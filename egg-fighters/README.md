# Chocolate Egg Fighters — прототип

3D-файтинг шоколадных яиц в стиле Roblox. Three.js, без сборки: открыть `index.html` в браузере
(или `?mode=demo` — бой CPU против CPU). План и разбор видео: [`docs/egg-fighters/PLAN.md`](../docs/egg-fighters/PLAN.md).

| Фаза | Что готово |
|---|---|
| 1 ✅ | Ниндзя и Самурай (одно тело-яйцо, разные костюмы), арена, камера |
| 2 ✅ | Движение, быстрые развороты, рывки, комбо тук-тук, отдача, подлёт, падение/вставание, хит-стоп, тряска камеры, следы ударов, крошки, финишер с затемнением и замедлением, CPU, HUD, меню, сенсорное управление |
| 3 | Три слоя (молочный → белый шоколад → жёлтая капсула) и 5 стадий разрушения |
| 4 | Физические куски шоколада, выпадение и открытие капсулы с игрушкой |
| 5 | Полный 1v1, звук, APK |

**Управление:** `WASD`/стрелки — движение, `J` — удар (жми тук-тук — комбо: удар, удар, разворот, добивание),
`K` — рывок (рывок + удар = удар с разбега), `L` — сильный удар (катана / меч). На телефоне — джойстик и 3 кнопки.

**URL:** `?mode=demo` — CPU vs CPU по кругу · `?p=ninja` / `?p=samurai` — сразу в бой · `?mode=showcase&view=ninja` — смотреть модель.

## Устройство
```
src/core.js                общие функции, пружины (инерция тела)
src/fighters/eggShape.js   профиль яйца: тело, слои шоколада, костюмы
src/fighters/model.js      общий риг: яйцо + блочные руки/ноги + глаза
src/fighters/costumes.js   ниндзя / самурай
src/fighters/roster.js     бойцы: статы и набор ударов (только данные)
src/fighters/fighter.js    состояние бойца в бою
src/fighters/movement.js   ходьба, развороты, рывок, отлёт, приземление, стены
src/fighters/animator.js   процедурные позы ударов и реакций
src/combat/moves.js        данные ударов (тайминги подобраны по видео)
src/combat/combat.js       комбо, попадания, реакции на удар
src/game/match.js          раунд: фикс. шаг 120 Гц, хит-стоп, замедление, события → эффекты
src/game/ai.js, input.js   CPU и игрок (одинаковый интерфейс)
src/fx/fx.js, audio.js     эффекты и синтезированные звуки
src/world/arena.js, camera.js
src/ui/hud.js, style.css
```
Новый боец = функция в `costumes.js` + запись в `roster.js`.

## Проверка фазы 2 (50 боёв CPU vs CPU, без отрисовки)
Таймаутов и зависших состояний нет, никто не вылетел за арену. Бой в среднем идёт ~15 с, за бой ~29 попаданий,
~7 подлётов и ~5 рывков. Стоят на месте 0,6 % времени. Пауза между ударами в комбо: медиана 0,28 с (в видео 0,2–0,3 с).
Победы: Самурай 28–32, Ниндзя 18–22 из 50.
