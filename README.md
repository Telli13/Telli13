# Mycelium Forest — прототип v2

Первая проба браузерной 2D-игры: вы управляете грибницей под лесом.

* **Сверху** — лес: фон, деревья, кусты, звери. **Снизу** — разрез почвы с камнями и ресурсами.
* **Клик по почве** — грибница растёт в ту сторону от ближайшей своей нити
  (можно зажать кнопку и вести). Камни не пропускают нити.
* **Ресурсы** (вода, органика, минералы, сахар): коснитесь нитью — ресурс утечёт по грибнице в общий запас.
* **Грибы** растут по 6 стадиям из общего запаса (сначала самый развитый).
* **Размножение** — зрелый гриб (6/6) можно кликнуть, а потом кликнуть по месту на поверхности:
  туда летят споры и появляется новая колония со своим узлом грибницы. Гриб-родитель откатывается до 4-й стадии.
* **Опасности**
  * личинки ползут к нитям и перегрызают их — отрезанная часть засыхает; клик по личинке прогоняет её;
  * ёж и заяц идут к грибу (над ними «!») и съедают его, белка хватает гриб и уносит;
    клик по зверю спугивает его. Съеденный гриб начинает расти заново.
* **Уровни** — 5 уровней с целями (колонии, зрелые грибы одновременно) и звёздами за время.
  Прогресс сохраняется в браузере. `Esc` — меню, `R` — перезапуск уровня, `?level=3` — сразу уровень 3.

| # | Уровень | Цель | Что нового |
|---|---------|------|------------|
| 1 | Пробуждение | 1 зрелый гриб | основы |
| 2 | Споры | 3 колонии | размножение |
| 3 | Личинки | 2 зрелых гриба сразу | личинки грызут нити |
| 4 | Голодные звери | 3 колонии + 2 зрелых сразу | ёж и заяц едят грибы |
| 5 | Белка-воришка | 3 зрелых гриба сразу | белка крадёт, много камней, мало ресурсов |

Свечение грибницы рисуется кодом (canvas: два слоя линий с `shadowBlur`,
наложенные в режиме `lighter` с «дыханием»), картинки мицелия из листа не используются.

## Как запустить

Нужен любой локальный веб-сервер (браузеры не дают странице грузить картинки
из `file://` надёжно). Проще всего — Python:

```bash
cd Telli13
python3 -m http.server 8000
```

Откройте <http://localhost:8000> в браузере.

Вариант на Node.js: `npx serve .` и откройте адрес, который он выведет.

## Структура

```
index.html            страница с canvas
src/game.js           вся логика и отрисовка
art/source/           исходные листы с картинками
art/sprites/          вырезанные объекты (PNG с прозрачностью) + фон
tools/cut_sprites.py  скрипт нарезки листов
```

## Нарезка спрайтов

Все объекты из листов вырезаны в `art/sprites/` скриптом:

```bash
pip install pillow numpy scipy
python3 tools/cut_sprites.py
```

Белый фон, соединённый с краем листа, становится прозрачным (с мягкими краями),
объекты находятся автоматически и сохраняются по именам в порядке чтения
(список имён — в начале скрипта). Если в лист добавить объект, допишите его имя в нужный ряд.

Известное ограничение: у пары ромашек на `daisies.png` чисто-белые лепестки,
касающиеся фона, получились полупрозрачными.
