# Mycelium Forest — прототип v3

Первая проба браузерной 2D-игры: вы управляете грибницей под лесом.

* **Большой мир**: 2400–4000 px в ширину и до 1800 px в глубину. Камера двигается стрелками / WASD,
  колесом мыши (Shift + колесо — по горизонтали), перетаскиванием неба, правой/средней кнопкой
  или кликом по мини-карте в правом нижнем углу.
* **Клик по почве** — грибница растёт в ту сторону от ближайшей своей нити (можно зажать и вести). Камни не пропускают.
* **Ресурсы** (вода, органика, минералы, сахар) утекают по нитям в общий запас. Глубже — богаче залежи.
* **Грибы** растут по 6 стадиям из запаса (сначала самый развитый).
* **Дети из корней** — когда гриб-мать дорос до 3-й стадии, ведите нить к самой поверхности
  (≥130 px от других грибов) — там проклюнется гриб-ребёнок. Курсор у поверхности подсказывает, можно ли.
  Ребёнок питается от той же грибницы; если личинка перегрызёт нить к нему — он погибнет.
* **Споры** — зрелую мать (6/6) можно кликнуть и выбрать место на поверхности: там начнётся новая
  колония со своими корнями. Мать откатывается до 4-й стадии.
* **Опасности** (клик по ним — прогнать):
  * заяц ест молодые грибы (стадии 1–3), ёж — взрослые (3–6), белка крадёт зрелые (5–6),
    синица пикирует на малышей (1–2). Детей звери выбирают охотнее. Съеденный ребёнок погибает,
    съеденная мать начинает расти заново;
  * личинки перегрызают нити (отрезанная часть засыхает), муравьи утаскивают ресурсы
    (если спугнуть муравья с добычей — он её бросит);
  * опасность за пределами экрана показывается красными метками по краям и на мини-карте; клик по метке — перейти туда.
* **Уровни** — 6 уровней с целями и звёздами за время; прогресс сохраняется в браузере.
  `Esc` — меню, `R` — перезапуск, `?level=3` — сразу уровень 3.

| # | Уровень | Цель | Что нового |
|---|---------|------|------------|
| 1 | Пробуждение | 1 зрелый гриб | основы, камера |
| 2 | Дети | 2 подросших ребёнка | дети из корней, заяц |
| 3 | Споры | 2 колонии + 2 зрелых сразу | споры, синица |
| 4 | Подземные воры | 3 подросших ребёнка | личинки, муравьи |
| 5 | Голодные звери | 5 грибов + 2 зрелых сразу | ёж, заяц, синица, личинки |
| 6 | Белка-воришка | 3 зрелых сразу + 2 ребёнка | все опасности, мало ресурсов |

Свечение грибницы рисуется кодом (canvas: два слоя линий с `shadowBlur`,
наложенные в режиме `lighter` с «дыханием»), картинки мицелия из листа не используются.

## Как запустить

Нужен любой локальный веб-сервер (браузеры не дают странице грузить картинки
из `file://` надёжно). Проще всего — Python:

```bash
cd Telli13
python3 -m http.server 8000
```

Откройте <http://localhost:8000> в браузере.

Вариант на Node.js: `npx serve .` и откройте адрес, который он выведет.

## Структура

```
index.html            страница с canvas
src/game.js           вся логика и отрисовка
art/source/           исходные листы с картинками
art/sprites/          вырезанные объекты (PNG с прозрачностью) + фон
tools/cut_sprites.py  скрипт нарезки листов
```

## Нарезка спрайтов

Все объекты из листов вырезаны в `art/sprites/` скриптом:

```bash
pip install pillow numpy scipy
python3 tools/cut_sprites.py
```

Белый фон, соединённый с краем листа, становится прозрачным (с мягкими краями),
объекты находятся автоматически и сохраняются по именам в порядке чтения
(список имён — в начале скрипта). Если в лист добавить объект, допишите его имя в нужный ряд.

Известное ограничение: у пары ромашек на `daisies.png` чисто-белые лепестки,
касающиеся фона, получились полупрозрачными.
